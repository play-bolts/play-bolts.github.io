# Imported grenade

**Stielhandgranate - German Grenade**, by
[Janovich](https://sketchfab.com/janovich3D).

- Original: https://sketchfab.com/3d-models/stielhandgranate-german-grenade-c49ce26939d64641afac1175a8d62338
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Runtime file: `imported-stielhandgranate.glb`
- Conversion manifest: `imported-stielhandgranate.provenance.json`

Modified for Bolts: removed the source presentation rotation; uniformly scaled
to 0.38 metres; placed the handle grip at the origin with the canister on +Y;
resampled the original base-color texture to 2K and the original normal and
metallic-roughness textures to 1K; renamed the attachment hierarchy. Original
geometry, UV layout and material-map roles are retained. The original creator
does not endorse these changes or Bolts.

The model is a carried prop with a vertical melee bash in Bolts. No throwing or
explosive gameplay is introduced by this asset conversion.
