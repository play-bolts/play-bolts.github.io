# Uniform fabric maps

Fabric030 by ambientCG, CC0 1.0 Universal.

- Source and preview: https://ambientcg.com/view?id=Fabric030
- Direct source archive: https://ambientcg.com/get?file=Fabric030_1K-JPG.zip

Selected files are the original 1024px color, OpenGL normal, and roughness maps. Color is sRGB; normal and roughness are linear data. The source cloth is neutral dark gray, so faction colors should be adjusted when tinting. No other archive content is distributed here.
